# FullChain3 - 多阶段攻击链

USE CVE:
Step1:CVE-2022-28524/CVE-2022-28525
Step2:CVE-2023-5002
Step3:CVE-2024-4956

## 攻击链概述

这是一个模拟真实网络环境的完整攻击链，包含三个CVE漏洞的串联利用：

### 网络拓扑

```
主机 (Attacker)
    ↓
┌─────────────────────────────────────┐
│           子网1 (172.26.0.0/16)    │
│  ┌─────────────────┐ ┌─────────────┐ │
│  │ CVE-2022-28524  │ │CVE-2023-5002│ │
│  │ ED01-CMS        │ │ PgAdmin     │ │
│  │ SQL注入+文件上传 │ │ RCE         │ │
│  │ 端口: 9001      │ │ 端口: 5051  │ │
│  └─────────────────┘ └─────────────┘ │
└─────────────────────────────────────┘
                    ↓ (通过5002跳板)
┌─────────────────────────────────────┐
│           内网1 (172.27.0.0/16)    │
│  ┌─────────────────────────────────┐ │
│  │      CVE-2024-4956             │ │
│  │      Nexus Repository          │ │
│  │      目录穿越漏洞              │ │
│  │      端口: 8081, 5005         │ │
│  └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

## 攻击流程

### 第一阶段：CVE-2022-28524 (ED01-CMS)
- **漏洞类型**: SQL注入 + 任意文件上传RCE
- **访问方式**: 直接暴露 (端口8888)
- **目标**: 
  1. 通过SQL注入获取CVE-2023-5002的登录凭据
  2. 通过文件上传获取RCE，读取`/tmp/flag.txt`
- **数据库中的凭据**:
  - 系统: pgadmin_system
  - 用户名: admin@admin.com
  - 密码: admin123
  - URL: http://cve-2023-5002-web:5050

### 第二阶段：CVE-2023-5002 (PgAdmin)
- **漏洞类型**: 远程代码执行 (RCE)
- **访问方式**: 需要登录 (端口5050)
- **目标**: 
  1. 使用从28524获取的凭据登录
  2. 利用RCE漏洞获取`/tmp/flag.txt`
  3. 作为跳板访问内网的CVE-2024-4956

### 第三阶段：CVE-2024-4956 (Nexus Repository)
- **漏洞类型**: 目录穿越
- **访问方式**: 仅通过内网访问 (端口8081, 5005)
- **目标**: 
  1. 通过5002作为跳板访问
  2. 利用目录穿越漏洞读取敏感文件

## 服务端口

| 服务 | 端口 | 描述 |
|------|------|------|
| CVE-2022-28524 | 9001 | ED01-CMS Web应用 |
| CVE-2023-5002 | 5051 | PgAdmin管理界面 |
| CVE-2024-4956 | 8081, 5005 | Nexus Repository |
| MySQL | 3306 | 共享数据库 |
| phpMyAdmin | 10080 | 数据库管理界面 |

## 环境变量

可以通过以下环境变量自定义端口：

- `FC3_ED01_PORT`: CVE-2022-28524端口 (默认: 9001)
- `FC3_PGADMIN_PORT`: CVE-2023-5002端口 (默认: 5051)
- `FC3_NEXUS_PORT`: CVE-2024-4956端口 (默认: 8081)
- `FC3_NEXUS_PORT2`: CVE-2024-4956端口2 (默认: 5005)
- `FC3_MYSQL_PORT`: MySQL端口 (默认: 3306)
- `FC3_PMA_PORT`: phpMyAdmin端口 (默认: 10080)

- CVE-2023-5002: `/tmp/flag.txt` 和 `/root/flag.txt`
- CVE-2024-4956: `/tmp/flag.txt` 和 `/root/flag.txt`

## 攻击路径

1. **初始访问**: 通过CVE-2022-28524的SQL注入获取凭据
2. **横向移动**: 使用凭据登录CVE-2023-5002
3. **权限提升**: 在CVE-2023-5002中利用RCE
4. **内网渗透**: 通过CVE-2023-5002作为跳板访问CVE-2024-4956
5. **最终目标**: 在CVE-2024-4956中利用目录穿越获取最终flag
